# Independent singing validation

The public benchmark uses the archived JamendoLyrics MultiLang dataset at commit f093b7a74e034deac21eb5ea3fc40769b29c35b0 (https://github.com/f90/jamendolyrics). Dataset authors Simon Durand, Daniel Stoller, Sebastian Ewert, ICASSP 2023; current dataset https://huggingface.co/datasets/jamendolyrics/jamendolyrics. It uses independently published manual word **onsets**, not the automatically derived end-of-line/word ending values, and three fixed German tracks, first 60 seconds each. The original audio and annotations are downloaded only in the runner temp directory, not uploaded or committed. No private media.

`python scripts/public_singing_benchmark.py` downloads the public model and data explicitly. Edit alignment is determined by text only; timing never chooses matches. WER is a normalized lexical diagnostic (Jam-ALT is the preferred transcription benchmark). Unmatched and invalidly timed words reduce all-word coverage at 100/200ms. Matched-only MAE and p95 are conditional and never imply accuracy over all words. Repeated lyrics can make the alignment ambiguous. The end boundary at 60 seconds can truncate a word; no claim of full-track accuracy. These few excerpts cannot establish generalization. A real-song release requires independent user-song annotations and wider representative validation. Successful workflow execution is not a passing model accuracy result. No publication approval.

## Remediation: paired real-model benchmark and caption-image QA

The separate public workflow attempts Demucs HTDemucs + Whisper and WhisperX on the same three fixed first-minute clips. It evaluates matched-onset and all-word coverage separately for raw mix, vocal stem ASR, and phoneme-aligned stem ASR. Reference timings are used only by the scorer, never by transcription/alignment. A completed run does not prove improvement; compare measured metrics on all three clips. No private files uploaded. Sylla is a candidate for a separate controlled benchmark; not implemented or certified here.

`vpp caption-image-qa video.mp4 --srt captions.srt --targets targets.json --panel 0.05 0.70 0.95 1.0` samples 3 points per cue and the midpoint of substantial gaps; checks German tokens in the panel and possible residual text in side/bottom strips. Use `--mode clean` for clean-source inspection, `--language deu+eng+ara` for optional multilingual OCR. Requires local FFmpeg and Tesseract data. OCR uncertainty and possible missing phrase anchors require review, never automatic guessed text. Optional project manifest `caption_image_qa: true` enables clean-source veto and review of burned draft; a blocked draft remains a review artifact, never a final output. Detection is sampled, not a proof of text absence.
